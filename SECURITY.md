# Security

This repository is a directory of links and original notes. It contains no secrets, no private facility information and no copies of third-party documents, and it must never be used to publish any of those.

- **A listed link has been compromised, redirects somewhere harmful, or now serves something other than what is described:** open a "Report a correction" issue with the resource ID and what you saw. Do not include live malware or exploit material.
- **Something in this repository looks like it exposes private or sensitive information:** open an issue that names the file but does not repeat the information, or email hello@okieotsec.com.
- The scripts use only the Python standard library, and the link checker only reads public pages. Lab exercises and assessment tools described by the catalog belong in isolated environments you own or are authorized to test.
